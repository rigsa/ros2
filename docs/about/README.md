# Acerca de este sitio

Este sitio contiene materiales de aprendizaje de ROS 2 adaptados para su uso en Panamá. Los recursos están diseñados para enseñar a los estudiantes cómo utilizar ROS 2 (Robot Operating System, Versión 2), mediante una combinación de aprendizaje en simulación (con el robot TurtleBot3 Waffle) y trabajo con hardware real. La mayor parte del aprendizaje inicial se realiza en simulación, tras lo cual los estudiantes pueden aplicar sus conocimientos de ROS 2 en los [robots del laboratorio](./robots.md) - plataformas cuadrúpedas Unitree (Go2 EDU, AS2 EDU y B2).

Este curso es desarrollado y mantenido por [RIGSA](https://rigsa.com) - Laboratorio de Robótica Industrial y Sistemas Autónomos de Panamá.
