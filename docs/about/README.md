# Acerca de este sitio

Este sitio contiene los materiales del curso de ROS 2 de [RIGSA](https://rigsa.com) - Laboratorio de Robótica Industrial y Sistemas Autónomos, Panamá. Los recursos enseñan ROS 2 (Robot Operating System, Versión 2) partiendo de simulación y progresando hasta los [robots del laboratorio](./robots.md): plataformas cuadrúpedas Unitree (Go2 EDU, AS2 EDU y B2).

El curso es desarrollado y mantenido por el equipo de RIGSA.
