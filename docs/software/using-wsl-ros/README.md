title: Acceder a WSL-ROS2 en las Computadoras del Laboratorio
---

**Aplicable a**: Participantes que no tienen una computadora personal con Windows 10 u 11.

## El Entorno de Simulación WSL-ROS2

Para apoyar este curso hemos creado un entorno personalizado de ROS 2 que se ejecuta en Windows 10 u 11 usando el [Windows Subsystem for Linux (WSL)](https://docs.microsoft.com/en-us/windows/wsl/){target="_blank"}. Lo llamamos "**WSL-ROS2**" y está disponible en las computadoras del laboratorio. 

## En el Laboratorio {#laboratorio}

WSL-ROS2 está **preinstalado** en todas las máquinas disponibles en el laboratorio.
